# 2. Переменные и типы данных

## Переменные

Переменная — это имя, ссылающееся на значение. Присваивание через `=`.

```python
age = 25
name = "Аня"
price = 199.9
is_active = True
```

Имена: латиница, цифры, `_`; не начинаются с цифры; регистр важен
(`age` и `Age` — разные). Пиши в стиле `snake_case`.

## Основные типы

| Тип | Что это | Пример |
|-----|---------|--------|
| `int` | целое число | `42`, `-7`, `0` |
| `float` | дробное число | `3.14`, `-0.5` |
| `str` | строка (текст) | `"привет"`, `'x'` |
| `bool` | логический | `True`, `False` |
| `NoneType` | «ничего» / пусто | `None` |
| `list` | список | `[1, 2, 3]` |
| `tuple` | кортеж | `(1, 2)` |
| `dict` | словарь | `{"a": 1}` |
| `set` | множество | `{1, 2, 3}` |

Узнать тип значения — `type()`:

```python
print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("hi"))      # <class 'str'>
print(type(True))      # <class 'bool'>
print(type(None))      # <class 'NoneType'>
```

## Приведение типов

Тип можно менять явно.

```python
x = int("10")      # строка -> число: 10
y = float("3.5")   # 3.5
s = str(42)        # число -> строка: "42"
b = bool(0)        # False (0 -> False, любое другое число -> True)

age = input("Возраст: ")   # это строка!
age = int(age)             # теперь число, можно считать
print(age + 1)
```

!!! danger "Частая ошибка новичков"
    `"5" + 5` вызовет ошибку — нельзя складывать строку и число.
    Нужно привести: `int("5") + 5` == `10`.

## None

`None` — специальное значение «ничего». Часто это результат функции, которая
ничего не возвращает, или «значение ещё не задано».

```python
result = None
if result is None:
    print("Значения пока нет")
```

Проверяют через `is None`, а не `== None`.

## Динамическая типизация

Одна и та же переменная может менять тип:

```python
x = 10       # int
x = "текст"  # теперь str — так можно, но злоупотреблять не стоит
```

## f-строки (форматирование)

Самый удобный способ вставить значения в текст — f-строка:

```python
name = "Аня"
age = 25
print(f"{name}, тебе {age} лет")   # Аня, тебе 25 лет
print(f"Через год будет {age + 1}")  # выражения тоже можно
```
