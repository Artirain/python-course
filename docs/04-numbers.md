# 4. Числа

Два основных типа: `int` (целые) и `float` (дробные).

```python
a = 10        # int
b = 3.14      # float
c = 2 + 3j    # complex — комплексное (нужно редко)
```

## Арифметика

| Оператор | Операция | Пример | Результат |
|----------|----------|--------|-----------|
| `+` | сложение | `2 + 3` | `5` |
| `-` | вычитание | `5 - 2` | `3` |
| `*` | умножение | `4 * 3` | `12` |
| `/` | деление (всегда float) | `10 / 4` | `2.5` |
| `//` | целочисленное деление | `10 // 4` | `2` |
| `%` | остаток от деления | `10 % 4` | `2` |
| `**` | возведение в степень | `2 ** 10` | `1024` |

```python
print(7 / 2)    # 3.5
print(7 // 2)   # 3  — отбросили дробную часть
print(7 % 2)    # 1  — остаток
print(2 ** 8)   # 256
```

!!! tip "Остаток % — полезный трюк"
    `n % 2 == 0` — число чётное. `n % 5 == 0` — делится на 5.

## Сокращённые присваивания

```python
x = 10
x += 5    # x = x + 5  -> 15
x -= 3    # 12
x *= 2    # 24
x //= 5   # 4
x **= 2   # 16
```

## Встроенные функции

| Функция | Что делает | Пример | Результат |
|---------|-----------|--------|-----------|
| `abs(x)` | модуль (без знака) | `abs(-7)` | `7` |
| `round(x, n)` | округление | `round(3.14159, 2)` | `3.14` |
| `min(...)` | минимум | `min(3, 1, 2)` | `1` |
| `max(...)` | максимум | `max(3, 1, 2)` | `3` |
| `sum(list)` | сумма | `sum([1, 2, 3])` | `6` |
| `pow(x, y)` | степень | `pow(2, 3)` | `8` |
| `divmod(a, b)` | (частное, остаток) | `divmod(17, 5)` | `(3, 2)` |

```python
print(round(2.5))        # 2 (банковское округление!)
print(round(3.14159, 2)) # 3.14
print(max([4, 8, 1]))    # 8
```

## Модуль math

Для более серьёзной математики подключают модуль `math`.

```python
import math

print(math.pi)         # 3.141592653589793
print(math.sqrt(16))   # 4.0 — квадратный корень
print(math.ceil(4.1))  # 5 — округление вверх
print(math.floor(4.9)) # 4 — округление вниз
print(math.factorial(5))  # 120
print(math.gcd(12, 18))   # 6 — НОД
```

## Числа и точность float

```python
print(0.1 + 0.2)   # 0.30000000000000004 (!)
```

Это не баг Python, а особенность хранения дробных чисел в компьютере.
Для денег используй округление или модуль `decimal`:

```python
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))   # 0.3
```

## Преобразования

```python
print(int(3.9))     # 3 — отбрасывает дробную часть
print(float(5))     # 5.0
print(int("42"))    # 42
print(round(3.9))   # 4 — а это округляет
```

## Системы счисления

```python
print(bin(10))   # '0b1010' — двоичная
print(hex(255))  # '0xff'  — шестнадцатеричная
print(oct(8))    # '0o10'  — восьмеричная
print(int("ff", 16))  # 255 — из hex обратно в int
```
