# 1. Введение

## Что такое Python

Python — высокоуровневый язык программирования. Его любят за читаемый синтаксис:
код похож на английский текст, а не на набор скобок и точек с запятой.

Где применяют:

- **Веб** (Django, FastAPI)
- **Данные и ИИ** (pandas, PyTorch, LLM)
- **Автоматизация и скрипты** (парсинг, боты)
- **Анализ данных, наука**

## Установка

1. Скачай Python 3.10+ с [python.org](https://www.python.org/downloads/).
2. При установке на Windows поставь галочку **«Add Python to PATH»**.
3. Проверь в терминале:

```bash
python --version
```

Должно вывести что-то вроде `Python 3.12.4`.

## Первая программа

Создай файл `hello.py`:

```python
print("Привет, мир!")
```

Запусти:

```bash
python hello.py
```

`print()` — встроенная функция, которая выводит текст в консоль.

## Комментарии

Комментарии игнорируются интерпретатором и нужны для пояснений.

```python
# Это однострочный комментарий
print("Работаем")  # можно и в конце строки

"""
Так оформляют
многострочный комментарий (на самом деле это строка).
"""
```

## Ввод от пользователя

```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```

`input()` всегда возвращает **строку**, даже если ввели число.

## Отступы важны

В Python блоки кода выделяются **отступами** (обычно 4 пробела), а не фигурными
скобками. Неправильный отступ — ошибка.

```python
if True:
    print("внутри блока")  # 4 пробела слева
print("вне блока")
```

!!! warning "Не смешивай табы и пробелы"
    Используй только пробелы (4 штуки). Большинство редакторов делают это
    автоматически.
