# Python с нуля

Практический курс по основам Python. Каждый урок — короткая теория, таблицы
встроенных методов и **запускаемые примеры**, которые можно скопировать и
проверить сразу.

## Для кого

- Тех, кто начинает с нуля.
- Тех, кто хочет освежить основы и подсмотреть «а как называется тот метод строки».

## Как учиться

1. Установи Python 3.10+ с [python.org](https://www.python.org/downloads/).
2. Читай урок сверху вниз, **набирая** примеры руками (не копируй — так лучше запоминается).
3. В конце каждого урока есть блок «Попробуй сам» — мини-задания.

!!! tip "Как запускать код"
    Сохрани код в файл `example.py` и запусти в терминале:
    ```bash
    python example.py
    ```
    Или экспериментируй прямо в интерактивной оболочке — набери `python` и жми Enter.
