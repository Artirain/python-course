# Глоссарий

Короткие определения терминов, которые встречаются в курсе.

**Переменная** — имя, которое ссылается на значение в памяти. `x = 5`.

**Тип данных** — «сорт» значения: число (`int`, `float`), строка (`str`),
логическое (`bool`) и т.д. Определяет, что со значением можно делать.

**Приведение (каст) типа** — превращение значения одного типа в другой:
`int("10")`, `str(42)`.

**Функция** — переиспользуемый блок кода, который вызывают по имени.
`print()`, `len()` или свои через `def`.

**Аргумент** — значение, которое передают функции при вызове: `len("abc")`.

**Параметр** — переменная в объявлении функции, куда попадёт аргумент.

**Метод** — функция, «привязанная» к объекту, вызывается через точку:
`"текст".upper()`, `[1, 2].append(3)`.

**Атрибут** — переменная, принадлежащая объекту: `dog.name`.

**Объект** — конкретный экземпляр типа/класса. `"abc"` — объект типа `str`.

**Класс** — «чертёж» для создания объектов с общими данными и поведением.

**Экземпляр** — объект, созданный по классу. `rex = Dog()` — экземпляр `Dog`.

**Наследование** — когда класс перенимает поведение другого класса.

**Итерируемый объект (iterable)** — то, что можно перебрать в цикле `for`:
список, строка, словарь, `range`.

**Индекс** — номер элемента в последовательности, с нуля. `s[0]` — первый.

**Срез (slice)** — часть последовательности: `s[1:4]`, `lst[::-1]`.

**Изменяемый / неизменяемый** — можно ли поменять объект после создания.
Списки, словари, множества — изменяемые; строки, числа, кортежи — нет.

**Ключ / значение** — пара в словаре: `{"ключ": значение}`.

**Область видимости (scope)** — где переменная «видна»: локальная (внутри
функции) или глобальная (во всём файле).

**Исключение (exception)** — ошибка во время выполнения, которая прерывает
программу, если её не перехватить через `try / except`.

**Модуль** — файл с кодом на Python, который можно импортировать.

**Пакет (package)** — набор модулей; ставится через `pip`.

**Библиотека** — модуль или пакет с готовым кодом для решения задач
(`requests`, `pandas`).

**Виртуальное окружение (venv)** — изолированная папка с зависимостями
конкретного проекта.

**REPL** — интерактивный режим Python (`>>>`), где команды выполняются сразу
по одной. Запускается командой `python` без имени файла.

**Синтаксис** — правила записи кода. Нарушил — `SyntaxError`.

**Отступ (indent)** — пробелы в начале строки; в Python задают вложенность
блоков (обычно 4 пробела).

**Комментарий** — текст после `#`, который интерпретатор игнорирует.

**f-строка** — строка с `f` перед кавычками, куда можно вставлять значения:
`f"{name}"`.

**Comprehension** — компактная запись создания списка/словаря/множества в одну
строку: `[x**2 for x in range(5)]`.

**Lambda** — короткая безымянная функция: `lambda x: x + 1`.
