# 8. Множества

Множество (`set`) — неупорядоченная коллекция **уникальных** элементов.
Дубликаты автоматически исчезают.

```python
nums = {1, 2, 3, 3, 2}
print(nums)          # {1, 2, 3} — повторы убраны

empty = set()        # именно set(), а не {} — это пустой словарь!
```

## Главное применение — убрать дубликаты

```python
names = ["Аня", "Боря", "Аня", "Вера", "Боря"]
unique = set(names)
print(unique)             # {'Аня', 'Боря', 'Вера'}
print(len(unique))        # 3 — сколько уникальных
print(list(unique))       # обратно в список
```

## Методы

| Метод | Что делает |
|-------|-----------|
| `add(x)` | добавить элемент |
| `remove(x)` | удалить (ошибка, если нет) |
| `discard(x)` | удалить (без ошибки, если нет) |
| `pop()` | вынуть произвольный элемент |
| `clear()` | очистить |
| `union(other)` | объединение |
| `intersection(other)` | пересечение |
| `difference(other)` | разность |

```python
s = {1, 2, 3}
s.add(4)         # {1, 2, 3, 4}
s.discard(2)     # {1, 3, 4}
print(3 in s)    # True — проверка вхождения (очень быстрая)
```

## Операции над множествами

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)   # {1,2,3,4,5,6}  объединение (union)
print(a & b)   # {3, 4}         пересечение (intersection)
print(a - b)   # {1, 2}         разность (difference)
print(a ^ b)   # {1,2,5,6}      симметрическая разность
```

| Оператор | Метод | Смысл |
|----------|-------|-------|
| `\|` | `union` | всё из обоих |
| `&` | `intersection` | общее для обоих |
| `-` | `difference` | что в первом, но не во втором |
| `^` | `symmetric_difference` | что только в одном из них |

## Практический пример

```python
python_devs = {"Аня", "Боря", "Вера"}
js_devs = {"Боря", "Гена"}

print(python_devs & js_devs)   # {'Боря'} — знают оба языка
print(python_devs | js_devs)   # все разработчики
print(python_devs - js_devs)   # {'Аня', 'Вера'} — только Python
```

!!! info "Почему множества быстрые"
    Проверка `x in set` работает почти мгновенно даже на миллионах элементов,
    в отличие от списка, где перебираются все элементы подряд.
