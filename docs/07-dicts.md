# 7. Словари

Словарь (`dict`) хранит пары **ключ → значение**. Быстрый доступ по ключу.

```python
user = {
    "name": "Аня",
    "age": 25,
    "is_admin": False,
}
empty = {}
```

Ключи обычно строки или числа (любой неизменяемый тип). Значения — что угодно.

## Доступ к значениям

```python
user = {"name": "Аня", "age": 25}

print(user["name"])       # Аня
# print(user["email"])    # ОШИБКА KeyError — такого ключа нет

print(user.get("email"))            # None — безопасно
print(user.get("email", "нет"))     # "нет" — значение по умолчанию
```

!!! tip "get вместо квадратных скобок"
    `get()` не падает, если ключа нет. Используй его, когда не уверен,
    что ключ существует.

## Добавление и изменение

```python
user = {"name": "Аня"}
user["age"] = 25          # добавили новый ключ
user["name"] = "Анна"     # изменили существующий
del user["age"]           # удалили ключ
print(user)               # {'name': 'Анна'}
```

## Методы словарей

| Метод | Что делает | Пример |
|-------|-----------|--------|
| `get(k, default)` | значение по ключу или default | `d.get("x", 0)` |
| `keys()` | все ключи | `d.keys()` |
| `values()` | все значения | `d.values()` |
| `items()` | пары (ключ, значение) | `d.items()` |
| `update(other)` | добавить/обновить из другого словаря | `d.update({"x": 1})` |
| `pop(k)` | удалить ключ и вернуть значение | `d.pop("age")` |
| `setdefault(k, v)` | вернуть значение или задать по умолчанию | `d.setdefault("x", [])` |
| `clear()` | очистить | `d.clear()` |
| `copy()` | копия | `d.copy()` |

## Перебор словаря

```python
user = {"name": "Аня", "age": 25}

for key in user:                 # по ключам (по умолчанию)
    print(key, user[key])

for key, value in user.items():  # сразу пары — так удобнее
    print(f"{key}: {value}")

print(list(user.keys()))     # ['name', 'age']
print(list(user.values()))   # ['Аня', 25]
```

## Проверка наличия ключа

```python
user = {"name": "Аня"}
print("name" in user)      # True
print("email" in user)     # False
```

## Вложенные словари

```python
users = {
    "u1": {"name": "Аня", "age": 25},
    "u2": {"name": "Боря", "age": 30},
}
print(users["u1"]["name"])   # Аня
```

## Частый приём: подсчёт

```python
text = "абракадабра"
counts = {}
for char in text:
    counts[char] = counts.get(char, 0) + 1
print(counts)   # {'а': 5, 'б': 2, 'р': 2, 'к': 1, 'д': 1}
```
