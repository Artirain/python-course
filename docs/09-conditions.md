# 9. Условия

Условия позволяют выполнять код только при определённых обстоятельствах.

## if / elif / else

```python
age = 20

if age < 18:
    print("Несовершеннолетний")
elif age < 65:
    print("Взрослый")
else:
    print("Пенсионер")
```

- `if` — проверяется первым;
- `elif` — «иначе если», можно сколько угодно;
- `else` — если ничего не подошло (необязателен).

Блок под условием выделяется отступом (4 пробела).

## Операторы сравнения

| Оператор | Смысл | Пример |
|----------|-------|--------|
| `==` | равно | `x == 5` |
| `!=` | не равно | `x != 5` |
| `>` | больше | `x > 5` |
| `<` | меньше | `x < 5` |
| `>=` | больше или равно | `x >= 5` |
| `<=` | меньше или равно | `x <= 5` |

!!! danger "Одно `=` и два `==`"
    `=` — присваивание (`x = 5`). `==` — сравнение (`x == 5`). Не путай.

## Логические операторы

| Оператор | Смысл | Пример |
|----------|-------|--------|
| `and` | И (оба истинны) | `age > 18 and age < 65` |
| `or` | ИЛИ (хотя бы один) | `day == "сб" or day == "вс"` |
| `not` | НЕ (отрицание) | `not is_admin` |

```python
age = 25
has_ticket = True

if age >= 18 and has_ticket:
    print("Пропускаем")

if not has_ticket:
    print("Нужен билет")
```

Можно писать цепочкой (только в Python):

```python
if 18 <= age < 65:      # то же, что age >= 18 and age < 65
    print("Взрослый")
```

## Что считается истиной

В условии значения автоматически приводятся к `bool`. **Ложными** считаются:

```python
False, None, 0, 0.0, "", [], {}, set()   # всё это — «ложь»
```

Всё остальное — «истина». Поэтому:

```python
name = input("Имя: ")
if name:                     # True, если строка не пустая
    print(f"Привет, {name}")
else:
    print("Ты не ввёл имя")

items = []
if not items:                # True, если список пустой
    print("Список пуст")
```

## Тернарный оператор (условие в одну строку)

```python
age = 20
status = "взрослый" if age >= 18 else "ребёнок"
print(status)     # взрослый
```

## Вложенные условия

```python
if logged_in:
    if is_admin:
        print("Панель админа")
    else:
        print("Личный кабинет")
else:
    print("Войдите")
```

## Оператор match (Python 3.10+)

Аналог `switch` из других языков:

```python
command = "start"

match command:
    case "start":
        print("Запуск")
    case "stop":
        print("Остановка")
    case _:                 # _ — «всё остальное»
        print("Неизвестная команда")
```
