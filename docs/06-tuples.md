# 6. Кортежи

Кортеж (`tuple`) — как список, но **неизменяемый**. После создания элементы
менять нельзя. Записывается в круглых скобках.

```python
point = (10, 20)
rgb = (255, 128, 0)
single = (42,)      # кортеж из одного элемента — запятая обязательна!
empty = ()
```

## Зачем нужны кортежи

- Защита от случайного изменения (координаты, настройки).
- Работают чуть быстрее списков и занимают меньше памяти.
- Могут быть ключами словаря (списки — не могут).

## Доступ к элементам

```python
point = (10, 20, 30)
print(point[0])     # 10
print(point[-1])    # 30
print(point[1:])    # (20, 30)
print(len(point))   # 3

# point[0] = 5  ->  ОШИБКА: 'tuple' object does not support item assignment
```

## Распаковка

Очень удобная возможность — разложить кортеж по переменным:

```python
point = (10, 20)
x, y = point
print(x, y)         # 10 20

# обмен значениями без временной переменной
a, b = 1, 2
a, b = b, a
print(a, b)         # 2 1

# «остаток» через *
first, *rest = (1, 2, 3, 4)
print(first)        # 1
print(rest)         # [2, 3, 4]
```

## Методы

У кортежа всего два метода (он же неизменяемый):

| Метод | Что делает | Пример | Результат |
|-------|-----------|--------|-----------|
| `count(x)` | сколько раз встречается | `(1,1,2).count(1)` | `2` |
| `index(x)` | индекс первого вхождения | `(1,2,3).index(2)` | `1` |

## Кортеж vs список

| | list | tuple |
|-|------|-------|
| Скобки | `[]` | `()` |
| Изменяемость | да | нет |
| Методов | много | 2 |
| Ключ словаря | нельзя | можно |

## Возврат нескольких значений из функции

Кортежи часто используют, чтобы вернуть несколько значений:

```python
def min_max(numbers):
    return min(numbers), max(numbers)   # это кортеж

lo, hi = min_max([4, 8, 1, 15])
print(lo, hi)      # 1 15
```
