# 3. Строки

Строка (`str`) — последовательность символов. Записывается в одинарных или
двойных кавычках.

```python
a = 'привет'
b = "мир"
multiline = """первая строка
вторая строка"""
```

## Базовые операции

```python
s = "Python"

print(len(s))        # 6 — длина
print(s[0])          # P — первый символ (индекс с 0)
print(s[-1])         # n — последний символ
print(s + "!")       # Python! — конкатенация
print(s * 3)         # PythonPythonPython — повтор
print("y" in s)      # True — есть ли подстрока
```

## Срезы (slicing)

`s[начало:конец:шаг]` — конец не включается.

```python
s = "Python"
print(s[0:3])    # Pyt
print(s[:3])     # Pyt (с начала)
print(s[3:])     # hon (до конца)
print(s[::2])    # Pto (каждый второй)
print(s[::-1])   # nohtyP (разворот строки)
```

## Методы строк

!!! info "Важно"
    Строки **неизменяемы**. Методы не меняют исходную строку, а **возвращают
    новую**. Поэтому результат нужно присваивать: `s = s.upper()`.

### Регистр

| Метод | Что делает | Пример | Результат |
|-------|-----------|--------|-----------|
| `upper()` | всё в ВЕРХНИЙ регистр | `"abc".upper()` | `"ABC"` |
| `lower()` | всё в нижний регистр | `"ABC".lower()` | `"abc"` |
| `capitalize()` | первая буква заглавная | `"привет мир".capitalize()` | `"Привет мир"` |
| `title()` | каждое слово с заглавной | `"привет мир".title()` | `"Привет Мир"` |
| `swapcase()` | инвертировать регистр | `"AbC".swapcase()` | `"aBc"` |

```python
name = "аНнА"
print(name.lower())        # анна
print(name.upper())        # АННА
print(name.capitalize())   # Анна
```

### Обрезка и очистка

| Метод | Что делает |
|-------|-----------|
| `strip()` | убрать пробелы по краям |
| `lstrip()` | убрать слева |
| `rstrip()` | убрать справа |
| `strip("xy")` | убрать указанные символы по краям |

```python
s = "   привет   "
print(s.strip())            # "привет"
print("...текст...".strip(".."))  # "текст"
```

### Поиск и проверка

| Метод | Что делает | Пример | Результат |
|-------|-----------|--------|-----------|
| `find(x)` | индекс первого вхождения или `-1` | `"abcabc".find("b")` | `1` |
| `rfind(x)` | индекс последнего вхождения | `"abcabc".rfind("b")` | `4` |
| `index(x)` | как `find`, но ошибка если нет | `"abc".index("b")` | `1` |
| `count(x)` | сколько раз встречается | `"aaa".count("a")` | `3` |
| `startswith(x)` | начинается с | `"file.txt".startswith("file")` | `True` |
| `endswith(x)` | заканчивается на | `"file.txt".endswith(".txt")` | `True` |

### Проверка содержимого

| Метод | `True`, если строка... |
|-------|------------------------|
| `isdigit()` | состоит только из цифр |
| `isalpha()` | только из букв |
| `isalnum()` | из букв и/или цифр |
| `isspace()` | только из пробелов |
| `islower()` | вся в нижнем регистре |
| `isupper()` | вся в верхнем регистре |

```python
print("123".isdigit())    # True
print("abc".isalpha())    # True
print("abc123".isalnum()) # True

age = input("Возраст: ")
if age.isdigit():
    print("Ок,", int(age))
else:
    print("Это не число")
```

### Замена и разбиение

| Метод | Что делает | Пример | Результат |
|-------|-----------|--------|-----------|
| `replace(a, b)` | заменить все `a` на `b` | `"a-b-c".replace("-", "+")` | `"a+b+c"` |
| `split(sep)` | разбить в список | `"a,b,c".split(",")` | `["a","b","c"]` |
| `rsplit(sep, n)` | разбить с конца | — | — |
| `splitlines()` | разбить по строкам | `"a\nb".splitlines()` | `["a","b"]` |
| `join(list)` | склеить список в строку | `",".join(["a","b"])` | `"a,b"` |

```python
csv = "яблоко,груша,слива"
fruits = csv.split(",")     # ['яблоко', 'груша', 'слива']
print(fruits[1])            # груша

back = " | ".join(fruits)   # яблоко | груша | слива
print(back)
```

!!! tip "split без аргументов"
    `"  a   b  c ".split()` разобьёт по любым пробелам и уберёт пустые:
    `['a', 'b', 'c']`. Удобно для разбора текста.

## Форматирование

### f-строки (рекомендуется)

```python
name, age = "Аня", 25
print(f"{name} — {age} лет")

price = 1234.5678
print(f"{price:.2f}")     # 1234.57 — два знака после точки
print(f"{price:,.2f}")    # 1,234.57 — с разделителем тысяч
print(f"{42:05d}")        # 00042 — дополнить нулями до 5 знаков
print(f"{0.25:.0%}")      # 25% — проценты
```

### Метод format (старее, но встречается)

```python
print("{} + {} = {}".format(2, 3, 5))   # 2 + 3 = 5
print("{name}".format(name="Аня"))
```

## Экранирование

| Последовательность | Значение |
|--------------------|----------|
| `\n` | перенос строки |
| `\t` | табуляция |
| `\\` | обратный слэш |
| `\"` | кавычка внутри строки |

```python
print("строка1\nстрока2")
print("путь:\tC:\\папка")      # табуляция и слэш
print(r"C:\новая\папка")        # r"" — «сырая» строка, \n не экранируется
```
