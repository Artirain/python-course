# 5. Списки

Список (`list`) — упорядоченная **изменяемая** коллекция. Может хранить любые
типы, в том числе вперемешку.

```python
fruits = ["яблоко", "груша", "слива"]
mixed = [1, "два", 3.0, True]
empty = []
```

## Доступ по индексу и срезы

```python
fruits = ["яблоко", "груша", "слива"]
print(fruits[0])     # яблоко
print(fruits[-1])    # слива (последний)
print(fruits[1:])    # ['груша', 'слива']
print(len(fruits))   # 3

fruits[1] = "банан"  # списки изменяемы
print(fruits)        # ['яблоко', 'банан', 'слива']
```

## Методы списков

| Метод | Что делает | Пример |
|-------|-----------|--------|
| `append(x)` | добавить в конец | `lst.append(4)` |
| `insert(i, x)` | вставить по индексу | `lst.insert(0, "первый")` |
| `extend(other)` | добавить все элементы другого списка | `lst.extend([5, 6])` |
| `remove(x)` | удалить первое вхождение `x` | `lst.remove("груша")` |
| `pop(i)` | вынуть и вернуть элемент (по умолчанию последний) | `lst.pop()` |
| `clear()` | очистить список | `lst.clear()` |
| `index(x)` | индекс первого вхождения | `lst.index("слива")` |
| `count(x)` | сколько раз встречается | `lst.count(2)` |
| `sort()` | отсортировать на месте | `lst.sort()` |
| `reverse()` | развернуть на месте | `lst.reverse()` |
| `copy()` | поверхностная копия | `lst.copy()` |

```python
nums = [3, 1, 2]
nums.append(4)      # [3, 1, 2, 4]
nums.sort()         # [1, 2, 3, 4]
nums.reverse()      # [4, 3, 2, 1]
last = nums.pop()   # last = 1, список [4, 3, 2]
print(nums, last)
```

!!! warning "append vs extend"
    `append([5, 6])` добавит **один** элемент — сам список `[5, 6]`.
    `extend([5, 6])` добавит **два** элемента: `5` и `6`.

## Сортировка

```python
words = ["груша", "яблоко", "банан"]

words.sort()                    # на месте, по алфавиту
words.sort(reverse=True)        # в обратном порядке
words.sort(key=len)             # по длине слова

# sorted() возвращает НОВЫЙ список, не меняя исходный
top = sorted([3, 1, 2])         # [1, 2, 3], исходный не тронут
```

## Полезные функции

```python
nums = [4, 8, 15, 16, 23]
print(len(nums))    # 5
print(sum(nums))    # 66
print(min(nums))    # 4
print(max(nums))    # 23
print(23 in nums)   # True — проверка вхождения
```

## Перебор в цикле

```python
fruits = ["яблоко", "груша", "слива"]

for fruit in fruits:
    print(fruit)

# с индексом
for i, fruit in enumerate(fruits):
    print(i, fruit)     # 0 яблоко / 1 груша / 2 слива
```

## Копирование — важный нюанс

```python
a = [1, 2, 3]
b = a          # b — та же самая ссылка! Меняем b -> меняется a
b.append(4)
print(a)       # [1, 2, 3, 4]  (!)

c = a.copy()   # настоящая копия
c.append(5)
print(a)       # [1, 2, 3, 4]  — не изменился
```

## Вложенные списки (матрицы)

```python
matrix = [

    [4, 5, 6],

```
