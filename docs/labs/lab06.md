# Лаб 6. Словари

!!! abstract "Коротко о главном"
    **Словарь (`dict`)** — коллекция пар `ключ: значение`. Доступ по **ключу**, а
    не по индексу. Ключ — неизменяемый тип (`str`, `int`, кортеж), значение —
    любое. С Python 3.7 порядок вставки сохраняется.

## Конспект

### Создание

```python
car = {"модель": "Audi A5", "цвет": "красный", "пробег": 100500}  # литералом
car = dict(model="Audi", color="red")        # через dict() — ключи станут строками
d = dict(zip(["a", "b"], [1, 2]))            # из двух списков: {'a': 1, 'b': 2}
z = dict.fromkeys(["север", "юг"], 0)        # общее значение: {'север': 0, 'юг': 0}
counts = {n: nums.count(n) for n in nums}    # генератор словаря
```

### Доступ, добавление, изменение

```python
d["ключ"]                 # значение по ключу (KeyError, если ключа нет)
d.get("ключ", "нет")      # безопасно: вернёт "нет", если ключа нет
d["новый"] = 10           # добавление или изменение
"ключ" in d               # проверка наличия ключа -> bool
len(d)                    # количество пар
```

### Перебор

```python
for key in d:            print(key, d[key])   # по ключам
for value in d.values(): print(value)         # по значениям
for k, v in d.items():   print(k, v)          # по парам
```

### Основные методы

| Метод | Что делает |
|---|---|
| `keys()` / `values()` / `items()` | ключи / значения / пары |
| `get(key, default)` | значение или default вместо KeyError |
| `setdefault(key, default)` | вернуть значение; если ключа нет — вставить |
| `update(other)` | дополнить/перезаписать из другого словаря |
| `pop(key)` | удалить и вернуть значение |
| `popitem()` | удалить и вернуть последнюю пару `(k, v)` |
| `del d[key]` | удалить пару (KeyError, если нет ключа) |
| `clear()` | очистить словарь |
| `copy()` | поверхностная копия |

!!! warning "Ключа может не быть"
    `d[key]` при отсутствии ключа кидает `KeyError`. Для безопасного чтения
    используй `get()`, для удаления — сначала `if key in d`.

## Задание

> Разработать словарь для определённой предметной области, протестировать
> функции и методы, применяемые к словарям.

Возьмём предметную область **«товар на складе»** и прогоним по нему все основные
операции.

??? success "Показать решение"

    ```python
    # --- Создаём словарь предметной области: карточка товара ---
    product = {
        "название": "Футболка",
        "размер": "XL",
        "цвет": "белый",
        "количество": 560,
        "цена": 1200,
    }

    # 1. Доступ к значениям
    print("Название:", product["название"])            # по ключу
    print("Скидка есть?", product.get("скидка", "нет"))  # get -> ключа нет, вернёт "нет"

    # 2. Длина и проверка наличия ключа
    print("Полей в карточке:", len(product))
    print("есть цвет:", "цвет" in product)              # True

    # 3. Добавление и изменение
    product["количество"] = 555      # изменили существующий ключ
    product["артикул"] = "TS-001"    # ключа не было -> добавился новый

    # 4. Перебор пар
    print("--- Карточка ---")
    for key, value in product.items():
        print(f"{key}: {value}")

    # 5. setdefault: вернёт значение, а если ключа нет — вставит
    product.setdefault("бренд", "NoName")  # бренда не было -> добавит "NoName"

    # 6. update: дополнить/обновить из другого словаря
    product.update({"цена": 999, "склад": "A1"})  # цену перезаписал, склад добавил

    # 7. Удаление
    removed = product.pop("артикул")   # удалить и вернуть значение
    print("Удалили артикул:", removed)
    del product["склад"]               # удалить пару по ключу

    # 8. Копия (независимый объект)
    backup = product.copy()
    print("Это разные объекты:", id(product) != id(backup))  # True

    # 9. Агрегация по числовым значениям
    prices = {"футболка": 999, "кепка": 500, "шорты": 1500}
    print("Сумма цен:", sum(prices.values()))
    print("Мин/макс:", min(prices.values()), max(prices.values()))
    ```
