# Лабораторные работы

Разбор лабораторных к экзамену: на каждую работу — **краткий конспект теории**
(только то, что реально нужно) и **решённое задание** с комментариями в коде.

!!! tip "Как пользоваться"
    Сначала прочитай конспект — он короткий и содержит главное. Потом разбери
    решение задания: код разбит на шаги, каждый прокомментирован. Набери его
    руками и запусти — так материал закрепляется перед экзаменом.

!!! warning "Про варианты"
    В работах №8, №9 и №10 задания разбиты по номерам вариантов — открой свой.
    Логика везде одинакова, меняются только исходные данные.
