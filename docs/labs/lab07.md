# Лаб 7. Работа с файлами

!!! abstract "Коротко о главном"
    Работа с файлом — три шага: **открыть → прочитать/записать → закрыть**.
    Надёжнее всего открывать через `with` — файл закроется автоматически.

## Конспект

### Открытие: `open(имя, режим)`

| Режим | Что делает |
|---|---|
| `r` | чтение (по умолчанию); файла нет — ошибка |
| `w` | запись; **перезаписывает** файл или создаёт новый |
| `a` | дозапись в конец; создаёт, если нет |
| `r+` | чтение + запись |
| `rb` / `wb` | то же, но бинарный режим |

!!! warning "Кодировка"
    Для русского текста указывай `encoding="utf-8"`, иначе на Windows возможны
    «кракозябры»: `open("f.txt", "w", encoding="utf-8")`.

### Два способа закрыть

```python
# Способ 1 — вручную
f = open("example.txt", "r", encoding="utf-8")
data = f.read()
f.close()                 # обязательно закрыть

# Способ 2 — with (рекомендуется): закроет сам, даже при ошибке
with open("example.txt", "r", encoding="utf-8") as f:
    data = f.read()
```

### Чтение

```python
f.read()          # весь файл одной строкой
f.read(10)        # первые 10 символов
f.readline()      # одну строку
f.readlines()     # список всех строк: ['стр1\n', 'стр2\n']
for line in f:    # построчно (экономно по памяти)
    print(line.rstrip())
```

### Запись

```python
f.write("текст")            # записать строку (перевод строки \n добавляй сам)
f.writelines(["a\n", "b\n"]) # записать список строк
```

### Прочее

```python
f.tell()                 # текущая позиция в файле
f.seek(0)                # перейти в начало
import os
os.rename("old.txt", "new.txt")   # переименовать файл
```

## Задание

> На основе лабораторной №2 организовать **табличный вывод в текстовый файл**
> результатов вычисления значений функции на заданном отрезке.

В лаб2 функция задавалась графиком (кусочно). Здесь для примера возьмём
конкретную кусочную функцию — под свой вариант достаточно заменить тело
`f(x)`. Считаем `y = f(x)` на отрезке `[a, b]` с шагом `h` и красиво пишем
таблицу `X | Y` в файл.

??? success "Показать решение"

    ```python
    def f(x):
        # Кусочная функция (подставь свою из варианта лаб2):
        #   x < 0      -> прямая y = 2x
        #   0 <= x < 3 -> парабола y = x^2
        #   x >= 3     -> константа y = 9
        if x < 0:
            return 2 * x
        elif x < 3:
            return x ** 2
        else:
            return 9

    # --- Параметры отрезка ---
    a = -2.0    # начало
    b = 4.0     # конец
    h = 0.5     # шаг

    # --- Записываем таблицу в файл ---
    with open("result.txt", "w", encoding="utf-8") as file:
        file.write("+============+============+\n")     # верхняя рамка
        file.write("I     X      I     Y      I\n")      # шапка таблицы
        file.write("+============+============+\n")

        x = a
        while x <= b + 1e-9:                # +1e-9 страхует от ошибок float
            y = f(x)
            # выравниваем числа по ширине 10, 2 знака после точки
            file.write(f"I {x:>8.2f}   I {y:>8.2f}   I\n")
            x += h

        file.write("+============+============+\n")

    # --- Проверим: прочитаем и выведем то, что записали ---
    with open("result.txt", "r", encoding="utf-8") as file:
        print(file.read())
    ```

    **Содержимое `result.txt` (и вывод на экран):**

    ```
    +============+============+
    I     X      I     Y      I
    +============+============+
    I    -2.00   I    -4.00   I
    I    -1.50   I    -3.00   I
    I    -1.00   I    -2.00   I
    I    -0.50   I    -1.00   I
    I     0.00   I     0.00   I
    I     0.50   I     0.25   I
    I     1.00   I     1.00   I
    I     1.50   I     2.25   I
    I     2.00   I     4.00   I
    I     2.50   I     6.25   I
    I     3.00   I     9.00   I
    I     3.50   I     9.00   I
    I     4.00   I     9.00   I
    +============+============+
    ```

!!! tip "Как адаптировать под свой вариант"
    Меняется только тело функции `f(x)` — перепиши ветки `if/elif/else` под свой
    график из лаб2 (участки прямых, парабол, полуокружностей). Отрезок `[a, b]`
    и шаг `h` бери из условия.
